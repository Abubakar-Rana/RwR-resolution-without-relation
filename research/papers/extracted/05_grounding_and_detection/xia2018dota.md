# DOTA: A Large-Scale Dataset for Object Detection in Aerial Images

- **Authors**: Gui-Song Xia, Xiang Bai, Jian Ding, Zhen Zhu, Serge Belongie, Jiebo Luo, Mihai Datcu, Marcello Pelillo, Liangpei Zhang
- **Year**: 2018
- **Venue**: CVPR 2018
- **arXiv**: 1711.10398
- **URL**: https://arxiv.org/abs/1711.10398
- **BibTeX Key**: `xia2018dota`

## Abstract
We present DOTA, a large-scale dataset for object detection in aerial images. DOTA contains 2,806 aerial images ranging from 800x800 to 4000x4000 pixels with 188,282 instances across 15 categories. Each instance is labeled with an oriented polygon to address arbitrary orientations and extreme aspect ratios. DOTA provides the foundation for benchmarking small, cluttered, and oriented targets in overhead imagery.

## Key Extracted Contributions
1. Standard computer vision detectors trained on natural photography degrade by 30-40% when applied to aerial nadir imagery.
2. Scale variation across overhead imagery requires multi-scale feature pyramids (FPN) and high-resolution cropping.
