# LHRS-Bot: Empowering Remote Sensing with Vision-Language Models

- **Authors**: Diliyaer Muhtar, Xueliang Lu, Pengfei Chen, et al.
- **Year**: 2024
- **Venue**: arXiv preprint
- **arXiv**: 2402.02544
- **URL**: https://arxiv.org/abs/2402.02544
- **BibTeX Key**: `muhtar2024lhrsbot`

## Abstract
Interpreting complex high-resolution remote sensing imagery requires understanding both global geographic context and localized fine-grained objects. We develop LHRS-Bot, a dedicated remote sensing VLM trained on multi-level aerial instructions. LHRS-Bot incorporates a hierarchical vision adapter that fuses multi-scale feature maps from remote sensing vision backbones. Extensive evaluations demonstrate superior performance on aerial scene understanding and regional question answering.

## Key Extracted Contributions
1. Multi-level instructions bridging scene-level context and object-level details improve VLM precision.
2. Hierarchical feature adapters outperform flat linear projectors on aerial benchmarks.
