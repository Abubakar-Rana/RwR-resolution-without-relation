# EarthGPT: A Universal Multi-Modal Large Language Model for Multi-Sensor Remote Sensing

- **Authors**: Zhenghang Zhang, Chenxi Ge, Shuai Ni, et al.
- **Year**: 2024
- **Venue**: IEEE TGRS 2024
- **arXiv**: 2401.16822
- **URL**: https://arxiv.org/abs/2401.16822
- **BibTeX Key**: `zhang2024earthgpt`

## Abstract
Remote sensing imagery encompasses diverse sensor modalities, including optical, Synthetic Aperture Radar (SAR), and infrared, each exhibiting distinct physical properties. We present EarthGPT, a universal multi-modal large language model capable of processing diverse remote sensing sensor inputs. EarthGPT utilizes unified sensor modality encoders and an instruction-tuned visual-linguistic connector. We curate a comprehensive multi-sensor visual dialogue instruction dataset. Evaluations indicate EarthGPT achieves competitive results across multi-sensor image classification, visual question answering, and fine-grained visual grounding.

## Key Extracted Contributions
1. Multi-sensor instruction tuning aligns diverse physical signatures into a unified language representation space.
2. Visual grounding queries achieve robust performance on standard resolution tiles.
