## Rules for AI Agents

1. **Keep Ground Truth Updated**: When new research requirements or scope constraints are decided with the user, update [`problem_statement.md`](file:///d:/projects/research/vlm/docs/problem_statement.md) immediately.
2. **Design Before Implementation**: Before writing non-trivial code in `src/`, draft architectural decisions and component interfaces in [`architecture_notes.md`](file:///d:/projects/research/vlm/docs/architecture_notes.md).
3. **No Unstructured Dumps**: Maintain clean Markdown with math blocks (`$$ ... $$`), Mermaid diagrams, and clear tables.
