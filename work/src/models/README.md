# Model Architectures (`src/models/`)

Houses implementations of Vision-Language Models, encoders, projectors, and token compression modules.

### Submodules Planned
- `encoders.py`: Vision encoder wrappers (SigLIP, CLIP, DINOv2).
- `projectors.py`: Cross-modal connectors (MLP, Resampler, Spatial Pooling).
- `vlm_base.py`: Base modular VLM container connecting vision and text.
