# Reference Materials & External Resources (`materials/`)

This directory stores references, links, dataset manifests, third-party benchmark pointers, and external code repositories relevant to the project.

---

## Directory Contents

- `references/`: Metadata files, dataset description JSONs, survey articles, and links to external repositories/weights.
- `benchmarks.md` *(optional)*: Summary of evaluation datasets (MMMU, MathVista, MMBench, POPE, etc.) and download scripts/links.

---

## Guidelines for AI Agents

1. **Keep Binaries Out**: Do not commit multi-gigabyte evaluation datasets here. Store download links, Hugging Face dataset IDs, and metadata schemas.
2. **Document Provenance**: For any third-party asset or benchmark cataloged here, note the license, source URL, and exact version.
